# Student Study Planner & Grade Dashboard

A simple web app for managing courses and assignments in one place.

## Features

- Add, edit, and delete courses
- Add, edit, and delete assignments
- Set assignment due dates, priorities, statuses, and grades
- View assignment and course grade averages
- Track completed, remaining, overdue, and due-this-week assignments
- Filter graded assignments and highlight assignments due this week
- Export assignments to a calendar `.ics` file
- Save data in the browser with `localStorage`

## Run Locally

Open `index.html` in a browser, or start a local server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Files

- `index.html` - page structure and forms
- `style.css` - layout and styling
- `app.js` - application logic and storage
